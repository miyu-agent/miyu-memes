# Miyu memes (miyu-memes)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This repository is Miyu's memes package (id `memes`). It provides a meme library in which every image carries a description and a note on how to use it; the AI picks an image from the library that fits the meaning of the conversation and sends it, and it can also save images it sees in a chat into the library. The package is also a plugin for the chat platforms, and you can turn it on or off for each group and each private chat.

## Install

Install Miyu first, then run:

```sh
miyu pkg install memes
```

Once installed, the package runs on its own, and you do not need to open it. The package can be installed on `linux-x86_64`, `macos-aarch64` and `windows-x86_64`. Installing it adds the following:

- Five tools for the AI: `meme_search`, `meme_send`, `meme_save`, `meme_edit`, `meme_delete`. In a session that cannot show images, the package counts as turned off.
- On each turn, there is a certain chance that the AI is reminded to add a meme. The related settings keys are `memes.reminder`, `memes.reminder_probability` and `memes.max_size_mb`.
- A dashboard page: open it with `miyu pkg page memes`, and you can upload, search, edit and disable memes there.
- The chat platforms plugin `Memes`, which is on by default.
- The bus methods `memes.add` and `memes.search` for other packages to call.

A ready-made image pack can be installed with `miyu pkg install memes-shorin-collection`. How to add images to the library, what each setting means, and what to do when something goes wrong are described in [Add-ons: Memes](https://github.com/miyu-agent/miyu/blob/main/docs/en/guide/addons.md#memes-memes).

## Development

The package is a Rust program, `miyu-memes`, that talks to the core only through the protocol and does not depend on any of the core's crates. The package folder is `package/`, which holds the manifest `package.toml`, the dashboard page `page/` and the plugin description for the chat platforms `im/plugin.toml`.

Development needs Rust; the version is the one in `rust-toolchain.toml`, and `rustup` installs it automatically. CI (`.github/workflows/ci.yml`) runs these checks on Linux, macOS and Windows:

```sh
cargo fmt --check
cargo clippy --all-targets --locked -- -D warnings
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --document-private-items --locked
cargo test --locked --no-fail-fast
```

In addition, every `.rs` file must be no longer than 500 lines, and test files count too.

To try an install on your own machine, put the built program into `bin/` in the package folder, then copy the package folder to a folder named `memes` and install it (the package id is taken from the folder name):

```sh
cargo build --release --locked
mkdir -p package/bin
cp target/release/miyu-memes package/bin/
cp -R package /tmp/memes
miyu pkg install /tmp/memes
```

On Windows, the program's file name ends in `.exe`. To publish a new version, push a `v<version>` tag; `.github/workflows/release.yml` builds one `.miyu` file for each system and uploads it to the release. The tag's version must match `version` in `package/package.toml` (change the version in `Cargo.toml` along with it).

The text the model sees (tool descriptions, parameter descriptions, tool results, reminders) is all recorded in `docs/prompt-ledger.md`.
