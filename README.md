# miyu-memes

Miyu 的表情包软件包：她能存、找、发表情包，按意思搜，隔一阵提醒她发一张；也是接入通讯平台（im）的插件，能按群开关。设计在核心仓库的 `docs/designs/34-表情包.md`，这里的 `docs/` 放这个包的施工顺序和登记簿。
