## miyu-memes 施工顺序（草稿，设计 34 落地）

仓库：miyu-agent/miyu-memes（公开）、miyu-agent/miyu-memes-shorin-collection（公开，项目主人 10-16 定）。
核心要的口子都在 main：user.append（X-16 补）、system.append（X-20，这个包不用）、model.embed（X-17）、[export]/packages.call（X-18）、tool.result.sent（X-19）。

M-1 骨架（做了，首个提交）
- Rust 一个 crate，程序 bin/miyu-memes；只走协议（stdin/stdout JSON-RPC），不依赖核心 crate；单元测试用假核心（`calls::Core` 特征）；跟真核心的端到端在 M-3 下。
- package.toml：[package] name 表情包、icon smile；[process] args=["serve"] start="always" capabilities=["tools","context.inject"]；[settings] 五项（设计 34 第六节）；[export] methods=["add","search"]；[page] dir="page" 随 M-4 下。
- CI 三台：fmt、clippy -D warnings、test、行数 500。Release：三平台打包 memes/ 文件夹（清单、page/、bin/）。
M-2 库和五件工具（做了，首个提交）
- 工作目录下 library.db（SQLite）只记 blob 编号和说明；图经核心 `blob.put {path}` 存成核心的 blob，不自己存一份。短编号是 sha256 的头 8 位。
- meme_search（关键词 + model.embed 向量，embedding_off 退回关键词）、meme_send（sent + sticker，end 默认真 → end_turn）、meme_save（本机路径读图、量宽高、存、去重）、meme_edit、meme_delete（停用）。
- 工具说明英文短句，量 token，包自己的登记簿（docs/prompt-ledger.md）。
M-3 提醒
- user.append：照 miyu-memes.reminder_probability、三个场所开关掷，中了交一块 <meme-hint>…</meme-hint>（英文，登记）。做了，首个提交；库里没有启用的图不提醒。
- 下（做了，10-16）：验收树 c7903e8c 的 release 核心 + 本机 embedding 包，真模型（deepseek-v4.1-flash）存两张（编号和旧版 index 的 sha256 头 8 位一致）、搜、发（`sent` 进了 tool.result）、概率调到 100 注入 `<meme-hint>`（`after:true`）她照着发了。实测改了一处：`meme_send` 原先写 `outbound`，每发一张都要人确认，`miyu ask` 里发不出去；它跟回的字一样是回话，改 `read`。
M-4 后台页和给别的软件调
- 上（做了，首个提交）package.methods：list/get/update/delete/restore/purge/upload；[export] add/search（from 记进 source.package）。
- 下 page/：网格、搜索、详情、传图（网页的独立整页规矩）。
M-5 内容包
- miyu-memes-shorin-collection：清单 [package] + 文件夹 memes/（index.json + images/，旧版 38 张原样）；miyu-memes 起来时照 package.list 找带 memes/ 的包、读进库（source.kind=pack），卸了拿掉没改过的。
